# Operator A — Level-3 Care Events / Intervention Evidence
**Role:** Lead the highest-priority OpenFARM Decision Index lane. **Branch:** `research/index-l3-care-events-2026-10`. **Ownership:** `docs/research/index-l3-care/`, `scripts/index_l3_care_*.py`, `tests/test_index_l3_care_*.py`, a branch-specific CI workflow if justified.

## Objective / deliverable
Find one **real, reconstructable animal-welfare care-event task** with observations before the event and independent clinically meaningful human action/outcome (e.g. livestock exam, treatment, lesion onset, lameness deterioration, emergency intervention). The deliverable is **source evidence plus a locally reproducible dataset builder**, not just a list of papers. If true action supervision is unavailable, identify strongest defensible *future adverse clinical outcome* task and preserve it as **L2→L3 candidate, not approved L3**.

Paper says 27 cases but source reconstructs 28 (Swiss seven vs six); pooled task quarantined. - PigWeb post-exposure hormones and human behavior are not pre-event real-time evidence, nor clinician decisions.
- A named caregiver-action task has **zero approved examples** in the current suite.

## Priority investigations (primary-source first)
1. **Pig audio/video plus real care actions**: Heseker et al. 2024 *Detecting tail biters by monitoring pig screams in weaning pigs*: https://www.nature.com/articles/s41598-024-55336-7 . Study reports 288 pigs in six pens/two batches; continuous audio/video, daily lesion observations and farm-staff identification/removal of seven biters in four pens. **Unknown: whether actual audio/video, dated actions, individual labels, full negative period are deposited.** Verify Data Availability and supplementary files; do not imply public media from publication alone.
2. **Agroscope pig ethogram + lesions**: original Zenodo https://zenodo.org/records/5920843. Previous partial audit read `animal.txt`, `conspecifics.txt` and `objects.txt` and saw 3/380 focal rows with active tail bites, but `lesions.txt` (34 KB) was not successfully joined. Retry original tiny tables; verify whether lesion changes are chronologically after independent precursor observation, subject keys, censoring, non-event cohorts. A valid future lesion task would be **clinical endpoint**, not a human intervention policy.
3. **2026 Aarhus/AU pig extensification study**: https://doi.org/10.5281/zenodo.18785731 (source indexed in https://pure.au.dk/portal/en/datasets/data-effects-of-single-extensification-factors-on-the-occurrence-/). Study mentions tail/ear biting, fouling, stomach ulcers. Verify dataset is real/public, actual file members, protocol and temporal grouping; don't assume real actions or treatment timestamps.
4. **Bite-o-Mat** https://doi.org/10.1016/j.atech.2025.101010 — 16 pens / 4 farms, daily lesion inspections. Test whether real original event timelines and device sensor histories are published and usable. A paper about alerts is not itself an alarm dataset.
5. Broaden beyond pigs if first four fail: veterinary reviewed on-farm records for foot disorders, mastitis, calf illness, broiler lesion inspections, morbidity/mortality intervention logs, companion-animal longitudinal veterinary triage. Exclude fabricated/demo/synthetic farm telemetry.

## Actual work
- Build ranked `docs/research/index-l3-care/source_gate.csv` with no more than 12 **top prospects**, including concrete URL/file verification, real intervention-vs-outcome status, measurable positives, negatives and animal/site counts.
- Deep-inspect the best **two** sources with bytes, hashes, parsed random real examples and adversarial leakage checks; one original primary case vignette/row with field mapping, redacted IDs in public reports.
- If a source passes, implement `build_*_historical.py` producing split state/reference/provenance and an explicit censor-aware event/forecast target. Unit test temporal cutoff, duplicate/group splitting, no pseudo-onset, missing controls, withheld labels.
- With enough truly independent event groups and representative source stream, run **constant prior and trivial trend** cheap baselines and report event-level precision/recall, timeliness, false alerts per animal/pen-day, class prevalence, uncertainty by farm. Otherwise give an evidence-backed failure and stop instead of pseudo-metrics.
- Separate three targets throughout: (a) future clinical deterioration, (b) **observed staff care event**, (c) **independently evaluated recommended action**; one does not establish the others.

## Exit / stop rule
At least **one fully byte-audited L3-adjacent true-outcome dataset** with honest admission gate, or a high-quality negative dossier proving what prevents admission; two fully inspected sources minimum. Don't get trapped in outreach: document blocked sources and move to public data. No model training or refactor.
