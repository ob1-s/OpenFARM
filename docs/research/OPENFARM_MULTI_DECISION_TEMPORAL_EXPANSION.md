# OpenFARM — multi-decision and historical-task expansion of the canonical v0.1 suite

> **IMPORTANT scientific correction, 2026-10-16:** The PigWeb section below is historical brainstorming and wrongly assumes human-coded stimulus-response behavior was *available at the PRE saliva timestamp* because the behavior CSV has the same timestamp key. The published experiment observes behavior **during exposure**, so that is **not a defensible PRE model feature**. Code now excludes all `observed_*` fields from PRE forecasting, keeps them separately for retrospective association, and the corrected v0.2 suite has **zero** genuinely synchronized multi-input PRE states. [Updated verified tasks, heldout baselines and admission verdicts](OPENFARM_HISTORICAL_TASK_VALIDATION_V0_2.md) supersede these proposals.



**Checkpoint: 15 Oct 2026, 23:44 BRT onward.** This is a **v0.2 proposal and audit queue**, *not* an amendment to the frozen [v0.1 canonical suite](OPENFARM_DECISION_SUITE_V0_1.md). Counts and admissions must not be conflated with dataset headline row counts or independent animal counts.

## Core thesis

**One source need not mean one decision.** The correct unit is `(observation cutoff, actual observable input, scientifically independent measured label, exact question, evaluation group, evidence gate)`. A single observation may support multiple questions in parallel: `Choice(posture)`, `Noul(behavior active)`, `Noul(future event starts)`, `Value(future instrument measurement)`. However, **one multiclass label rewritten as 15 binary labels is not 15 independent lines of supervision**; these must share an evaluation family and correlated labels.

In historical tasks, source-time order is mandatory: `state at or before t -> independently observed label after t`. Do not use a future timestamp, future-derived feature or target transformation as input. For state changes measured during a current window, mark clearly whether the label is past/current *measurement* or a genuine *future outcome*. Separate forecasting from simple re-expression of the input.

## First concrete historical candidate — implementation verified

**PigWeb source-pinned v0.2 builder has now passed independent clean CI:** [GitHub Actions run 38842843569](https://github.com/ob1-s/OpenFARM/actions/runs/38842843569), `scripts/build_pigweb_historical_v02.py`. It validates all original 256 behavior observations, 496 physiology rows, 248 behavior/physiology paired sessions, exactly **124 unique animals** in four institutes, synchrony of behavior and `pre` timestamps and strictly later `post` readings (21–127 minutes).

The script prepares **four leave-one-institute-out site protocols**, with only pre-session observations and pre-session physiological measurements in the model features and independent post-session change as each task label; subject and site/date/context keys are stored *only* in provenance and split metadata. It provides Noul classification and continuous deltas from **two distinct independent assays**. The same cortisol `increase` versus `delta` is *one* measured endpoint rendered in different output types; do **not** call them separate ground-truth sources.

| Heldout site | Independent pigs | Paired sessions | Cortisol increases / valid pairs | Oxytocin increases / valid pairs |
|---|---:|---:|---:|---:|
| AU | 20 | 40 | 13 / 36 | 15 / 35 |
| INRAE | 35 | 70 | 43 / 65 | 23 / 43 |
| IRTA | 23 | 46 | 22 / 46 | 21 / 44 |
| WUR | 46 | 92 | 65 / 87 | 43 / 88 |
| **Total** | **124** | **248** | **143 / 234** | **102 / 210** |

**Note strong cross-site shifts:** cortisol increases in 36% of AU valid sessions but 75% of WUR sessions. This means a pooled random-record split could be seriously misleading; whole-site heldout is the right first scientific stress test. Eye infrared rise has **25/40** positive paired outcomes but **all 40 are AU only**, so no site-heldout evaluation of that variable is possible.

**Gate:** `ACTUAL_DATA_AND_GROUP_AUDIT_PASSED; MODEL_TASK_VALIDATION_PENDING`. No trained PigWeb model/baselines yet; no proof of independent affect or care outcomes. Physiology alone is not an empathy rating or human-attention label. Timestamps are known for source validation, but `post` time was not made a model input.

**Primitive note:** v0.1 implements `Noul`, `Choice`, `Score`; proposed `Value` / `Count` regressions require a new typed output and matching verifiers. They must not be represented as already running in v0.1.

## Build-order recommendation

1. **PigWeb historical response task family**: source *pre* behavior/hormones -> later independent hormone changes. First explicitly freeze a leave-one-institute-out split, censored source timestamps, group IDs, label missingness, proper regression and classification references. Crucially decide in advance whether the task is **predicting measured physiology** (valid) or emotion (not supported).
2. **Big Broiler multiple observed behaviors + quality/abstention**: separately score posture, multi-label action, feather peck, exploration/preening, and event onset with whole-video group split, human pairwise reliability and naive persistence baseline. Don't pretend rare events are numerous independent cases.
3. **HotPig 15-min future feeder-onset**: first real prospective structured-state candidate from already approved source, with strict future cutoff, separate event episodes and animal-heldout metrics; then assess future-hour feeder budget and per-pig deviations.
4. **Meerkat video-future behavior**: complete within-video track continuity audit and causal timing, next behavior/onset/persistence baselines on 12/4/4 *whole-video* partitions.
5. **External outcome escalation**: two-farm tail-biting and linked clinical lesion/resilience outcomes only after actual source-file and scientifically valid event-onset adjudication; **do not invent a Level-3 caregiver target today**.

This yields several **question families** from four usable datasets **without falsely counting them as independent new welfare benchmarks**. Evaluate each task family at multiple natural output types, horizons, or evidence levels with explicit shared-source dependency. No generic animal happiness label is warranted by these archives.
