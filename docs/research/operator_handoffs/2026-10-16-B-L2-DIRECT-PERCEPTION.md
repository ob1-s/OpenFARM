# Operator B — Direct Welfare Perception / Level-2 Benchmark
**Role:** Produce the first genuinely sensory welfare-interpretation evaluation, if evidence warrants it. **Branch:** `research/index-l2-direct-welfare-2026-10`. **Ownership:** `docs/research/index-l2-perception/`, `scripts/index_l2_*.py`, `tests/test_index_l2_*.py`.

## Objective / deliverable
**Actually inspect original images or recordings and expert ordinal/clinical labels** and construct one small, reproducible, animal-disjoint `Score`/`Noul` benchmark that measures a defensible pain-associated cue, clinical condition, gait abnormality, lesion, or other welfare-related reference from *observable* visual/pose/audio input. Primary target is a single clean dataset, NOT 'emotion recognition', 'needs vet' relabeled from a grimace score, or a fancy model.

## Existing knowledge
- Legacy Horse Grimace survived forensic review as 7 horses, 5 train/2 test, 829 balanced train and 279 test crops; narrow **regional** score 0/1/2 from one annotator, no reliable clinical pain adjudication; keep as a tiny seed, not benchmark gold.
- EquiFACS clinical independent-vet AU-occupancy pilot 54 codeable intervals / 18 media, only five test media, heldout logistic Brier 0.481 vs prior 0.409 and AUROC 0.229. Source expert AU codes were *not* pixels and some clinical videos unavailable.
- Repo pre-triage: `docs/research/2026-10-direct-perception-welfare-triage.md`.

## Primary acquisition / forensic investigation
1. **GrimACE / Mouse Grimace**: https://zenodo.org/records/18299984 ; code https://github.com/ETHZ-INS/GrimACE_manuscript . Manuscript describes 1,245 expert-scored face images from 31 mice and five facial action ratings with explicit unrateable. Source code uses HDF5 `images`, `bounding_boxes`, `labels`, and per-fold `fold_ranges` for 31-fold evaluation. **Source `Data.zip` (~3.8 GB) not actually downloaded in last triage.** Investigate files/byte-range/sample strategically before full transfer. Prove full image↔label↔mouse ID alignment, no near-duplicate cross-animal/group leakage, real 0/1/2+unrateable distributions and data-specific license. This is a *pain-associated visual cue* task, not proof of true pain.
2. **HAF horse faces**: https://zenodo.org/records/14541977 (233.8 MB archive; 605 images/11 horses/22 videos reported), backup for immediate image-first audit. The 1fps names encode *video* ID, not necessarily horse ID. Need independently recover actual animal IDs, class generation process and rights. 25fps alternative: https://zenodo.org/records/17389614 (5.5GB, don't blindly download).
3. **Genuinely clinical alternative**: 2026 independent human chicken footpad dermatitis/hock-burn scoring study https://doi.org/10.1016/j.psj.2026.106968 , paper https://pmc.ncbi.nlm.nih.gov/articles/PMC13141726/ reports 500 validation bird images / two slaughterhouses and three assessors. **Zenodo https://zenodo.org/records/19885754 contains ONLY the publication PDF and HTML assets, not evidence of released scoring images or tables**. Locate original image/label files lawfully; blocked until proven usable. Slaughter-line recognition is a retrospective clinical indicator and should not be sold as on-farm intervention.
4. Optional direct-clinical pose: 2026 cow pose trajectories https://github.com/hrussel/lstm-lameness-detection (272 trajectories, 98 cow IDs verified earlier) **dataset license missing**. 215 ten-rater cattle gait videos described at https://animalwelfarehub.org/cows-project/ but no actual files found earlier. No correspondence critical path.

## Actual work
- Source metadata and sample manifest incl. images with source IDs/hashes, labels, raters and source rights; make a small **actual-source sample gallery for local review** (do not commit third-party images if rights uncertain); source-statistics report with per-mouse/video, class/rater, key scene and timestamp clustering.
- Explicitly audit expert-label validity and potential circularity (pain condition/treatment/group as 'ground truth'); classify primary reference as human *facial action score*, veterinarian clinical score or actual clinical state with caveats.
- Proposed typed `Score` ordinal full distribution and `not_rateable`/abstain. Other questions only if independently referenced, not threshold multiplication advertised as biological diversity.
- Animal-disjoint train/cal/test or leave-one-animal-out as data permit. Verify actual IDs/group structure, group count per fold, source duplication, near duplicates, source camera/treatment cues. If only tiny groups, publish an exploratory *pilot* with wide group uncertainty, not leaderboard ranking.
- Cheap controls: source class prevalence, image quality-only/background-only, simple frozen embeddings + tiny head if feasible. If training demands days/GPU, stop at task validation.
- Tests: original-byte hash, filename-label alignment, no source group overlap, masking of unrateable, deterministic split and no label/site leakage. Short README for local source rebuild. Emit **one scored actual-source exemplar** with no image redistribution violations.

## Exit / stop rule
One independently inspected visual welfare-proximal task with complete source/rights/split/label dossier and runnable build, **or** a precise no-admission report with proof why top two alternatives fail. No large model training.
