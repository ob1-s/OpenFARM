# Operator C — Farm Behavioral Event Observation / L1→L3 Bridge
**Role:** Turn *real farm sensing* into welfare-relevant event datasets with defensible temporal monitoring metrics and potential eventual linkage to care decisions. **Branch:** `research/index-behavior-to-care-2026-10`. **Ownership:** `docs/research/index-behavior-events/`, `scripts/index_behavior_*.py`, `tests/test_index_behavior_*.py`.

## Objective / deliverable
Admit at least one **observation/event** task on actual raw video/audio/sensors with independent manual labels and real animal/site/video-disjoint evaluation, emphasizing damaging interactions, gait abnormalities or credible welfare-relevant event detection. Seek a SECOND independently observed clinical consequence or recorded care event in same actual animal/pen/timeline; **never manufacture Level 3 from 'feather pecking' alone**.

## Existing evidence & don't duplicate
- HotPig independent electronic feeder vs camera-generated 12 counts is already approved as instrument agreement only (24 pigs, 16/4/4 split; tiny tree F1 0.759, about 12.66 false-positive *minutes*/pig-day), not welfare.
- Cattle wearable motion index vs video reviewed 4-way behavior classification is approved research L1, but no time-consistent cow signal, high log loss.
- Meerkat 15-way geometry/motion observation task already approved noncommercial, video-heldout macroF1 0.266. Not a welfare alert.
- Big Broiler source audit, `docs/research/2026-10-video-heldout-sprint.md`: 102 videos with actual human per-frame/track actions; 10 triple-annotated videos, 5,984 sampled samples and human pairwise F1 for `Feather_Pecking` 0.824 **but only 45 positive sampled rows across six videos**. `Out_Of_Sight` F1 0.791. Actual source archive ~32.5 GB; prior audits used remote ZIP range reads to isolate 10 CSV files (avoid full 32GB download initially). Does NOT measure injury or caretaker decisions. Published AGPL-3.0; confirm data/media rights and terms.

## Priority candidate sources
1. **Big Broiler** https://github.com/decide-ugent/big-broiler-dataset . Retrieve original annotation timing and optionally small matched video clips. Focus on feather-pecking/other harmful observed interactions, posture loss, `Out_of_sight` and **time-local episodes**, not just frame labels; use 3-person disagreement where available. Inspect source camera and setup shifts.
2. **ChickenVerse 2026** original https://zenodo.org/records/20672799 ; https://github.com/amirivojdan/ChickenVerse . Reported 15,250 annotated individual video behavior clips, five poultry facilities, CC BY-NC-SA restrictions in previous OpenFARM audit. Check actual clip-level labels and presence of adverse/abnormal welfare-relevant behaviors; ensure farm/animal/video-heldout, not overlapping crops of same frames. Do not claim clinical consequences from action labels.
3. **Tail biting / pig screams**: Article https://www.nature.com/articles/s41598-024-55336-7 reports synchronized audio/video, 288 pigs, 7 biters removed by staff, but the paper explicitly says data **are not publicly available due to privacy concerns**, available only on request. Do not spend time on gated access; coordinate with Operator A only if legally accessible data independently appear; **A owns care labels/events**, **C owns audio/video perception**. Do not compete for same files or rebuild historical task.
4. **Open pig skeleton/RGB 2026** https://zenodo.org/records/20370788 (5.5GB, old audit no explicit rights). Large file if needed only after access/rights/behavior relevance verified. Restricted companion paired pig wearable audio+accelerometer https://zenodo.org/records/20370059 is NOT publicly downloadable despite indexed 'Open' page; exclude from critical path.
5. **Pig/cow low-cost acoustic events**: cattle jaw/rumination dataset https://doi.org/10.6084/m9.figshare.c.6465301.v1 has five cows and 392h human-labeled bouts; useful spectrogram baseline but *ordinary feeding* should be secondary if the task is not tied to distress/clinical outcomes.

## Actual work
- Choose **ONE high-value real-source video/audio event target**, preferably `Noul(abnormal or harmful observable event present in past/current 5–30s)` plus `Noul(unscorable/occluded)` as separately measured observation status. Never classify positive/negative emotion based only on action name.
- Compile independent video/group-heldout train/cal/test windows; event-level onset/offset, source identity, label origin, prevalence across real time, annotated clip selection process, hard negatives, duration and evidence for true absence; avoid treating unannotated windows as negative.
- Report frame-level and episode-level human agreement with time tolerance; source behavior vs clinically damaging classification; event prevalence, group counts, camera/site shifts and realistic **false event detections/hour** as source observation metric (NOT caretaker false alerts/day).
- Build simple data loader/source builder, unit tests, source example inspection, deterministic cheap baseline if reliable source splits permit (one frozen image encoder or simple pose/motion and threshold, NOT any frontier model). For a large official archive inspect manifest and use remote range reading/restricted small sample first; full media only if passing source gates.
- Explicit collaboration contract: if credible clinical injury/treatment alignments exist, publish join schema+candidate action-time questions and pass to Operator A; do not silently invent care labels.

## Exit / stop rule
Produce one real, reproducible, source-verified welfare-relevant observable event task and **explain exactly why it is L1 versus L2/L3**, or show decisive blockers and the next strongest alternative. A second dataset only if first source decisively passes/fails.
